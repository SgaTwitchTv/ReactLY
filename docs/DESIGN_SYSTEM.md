# ReactLY design system

## Direction

Dark, cinematic, energetic, and unmistakably social-camera focused. The
interface should feel credible and premium without copying TikTok.

## Brand

- Name: `ReactLY`
- Spoken like “reactly”
- Positioning: `Don't comment. React.`
- Finished content unit: `Rect`

## Colors

| Token | Value | Use |
|---|---:|---|
| Canvas | `#070707` | App and export background |
| Panel | `#111214` | Cards and recorder shell |
| Raised panel | `#191A1D` | Controls |
| Lime | `#C7FF35` | Primary action and camera/source outline |
| Violet | `#7C3CFF` | Secondary energy and glow |
| Coral | `#FF3F58` | Recording state |
| Text | `#F6F7F2` | Primary copy |
| Muted | `#9B9D98` | Secondary copy |
| Hairline | `rgba(246,247,242,.16)` | Borders |

## Typography

- Display: condensed, bold, high-impact. Use a properly licensed bundled font
  before production.
- Interface: modern neutral sans-serif.
- Headlines are uppercase, tightly tracked, and short.

## Components

- Pill-shaped lime primary button
- Dark recorder shell
- Coral circular record control
- Lime-outlined source/camera PiP card
- Compact recording timer
- Restrained violet/lime ambient glow
- Subtle brand watermark during exported transition

## Motion

- UI motion should be quick, physical, and restrained.
- Respect reduced-motion settings in the application.
- Exported-format motion follows `CAPTURE_FLOW.md`.
- Avoid arbitrary bouncing, looping decoration, and excessive glassmorphism.
